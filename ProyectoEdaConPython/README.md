# ProyectoEdaConPython

Esta carpeta agrupa los documentos y scripts del proyecto de Análisis Exploratorio de Datos (EDA) con Python.

Estructura sugerida dentro de esta carpeta:

- data/           # datos crudos y procesados (no subir datos sensibles)
- notebooks/      # notebooks Jupyter (.ipynb)
- scripts/        # scripts Python reutilizables
- reports/        # informes y visualizaciones finales
- README.md       # este archivo
